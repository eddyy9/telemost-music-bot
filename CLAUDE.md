# Контекст проекта для Claude Code

## Что это

Музыкальный бот для Яндекс Телемоста. Заходит на встречу отдельным участником
и играет звук. Сейчас — терминальное приложение на Python. Идёт переезд в
десктоп-приложение на Electron (план: `docs/PLAN-V2.md`).

## Текущая архитектура (версия v1.0-cli)

```
bot.py      — терминальный интерфейс, цикл команд
audio.py    — плеер: yt-dlp -> ffmpeg -> float32 PCM -> sounddevice -> CABLE Input
browser.py  — Playwright: поднимает Chrome/Edge, патчит getUserMedia на CABLE Output,
              правит SDP под Opus 128 кбит/с стерео, автоклик по кнопкам входа
diag.py     — диагностика микрофона: реестр Windows, устройства, браузер
```

Звук идёт через виртуальный кабель VB-Audio: питон пишет PCM в `CABLE Input`,
браузер бота считает `CABLE Output` своим микрофоном.

## Куда движемся

Electron-приложение, внутри которого два webview: пользователь и бот.
Playwright и внешний браузер исчезают — Electron сам Chromium.
VB-Cable становится запасным путём: основной — синтетический микрофон
через WebAudio внутри webview.

Python остаётся как аудио-ядро без интерфейса, общается с Electron по
локальному WebSocket.

## Правила работы в этом репозитории

### Git

- `main` — только то, что реально работает. Не коммитить туда напрямую.
- `v2/desktop` — ветка обновления, основная рабочая.
- `spike/*` — эксперименты. Не мержатся: из них выносится вывод, потом ветка удаляется.
- Тег `v1.0-cli` — точка возврата к рабочей терминальной версии. Не удалять, не перемещать.
- Перед рискованным шагом ставить тег `wip/<что-делаю>`. Теги ничего не стоят.
- Коммиты по-русски, в теле — **почему**, а не что. Как в существующей истории.
- Если файл переезжает — `git mv`, не копирование. История файлов важна.

### Что нельзя трогать без явной просьбы

- **DSP-тракт в `audio.py`**: лимитер, `loudnorm`, размеры буфера, порядок фильтров
  ffmpeg. Всё это подбиралось экспериментально, комментарии в коде объясняют
  почему именно так. В частности: `aresample` обязан стоять после `loudnorm`
  всегда, иначе поток уходит на 192 кГц.
- **Правку SDP в `browser.py`**: `maxaveragebitrate` правится во **входящем**
  описании, это не опечатка (RFC 7587: параметр приёмника ограничивает отправителя).
- `positions.json` и `history.log` — рабочие данные пользователя.

### Стиль

- Комментарии и сообщения пользователю — по-русски.
- Комментарий объясняет причину решения, а не пересказывает код.
- Текст внутри `.bat` — **только английский**: cmd.exe ломается на кириллице
  и начинает выполнять обрывки строк как команды.
- Окончания строк задаёт `.gitattributes`. Не переписывать файлы целиком.

### Проверка перед коммитом

- `git diff -w --stat` — если правок по существу нет, а diff большой, значит
  поехали окончания строк. Разбираться, а не коммитить.
- Терминальная версия должна продолжать запускаться: `start.bat` -> `selftest`.
